## 1. What this project is

**PalmAstro · 掌紋星象** — a privacy-first self-reflection app (Android + iOS) that scans the user's
palm entirely on-device, blends the extracted line/geometry signals with real tropical-astrology math,
and produces **explainable monthly guidance**: what to lean into, what to be mindful of, and a gentle
week plan. Taiwan-first launch, English + 繁體中文.

Non-negotiable product rules (PRD): no cloud processing of palm data, no medical/financial/deterministic
claims (a safety filter gates every generated sentence on both platforms), no fear-based copy, no ads,
no accounts, delete-everything as a first-class flow. Free-only at launch (`iap_enabled=false`;
product IDs reserved in `contracts/ProductIds`).

**Architecture in one line:** one deterministic "brain" (ruleset + content templates + safety rules as
versioned JSON, byte-identical on both platforms, proven by generated parity fixtures) inside two
native bodies (Kotlin/Compose · Swift/SwiftUI).

| Area | Location |
|---|---|
| Android app | `app/` (Compose, Material 3, Hilt, SQLCipher via Keystore-wrapped key) |
| Engines (Kotlin) | `engine-scan-quality/ -palm-features/ -astro/ -scoring/ -content/` |

**Key decisions log** (all labeled `Assumption (editable)` where applicable): free-only launch; UI
languages en + zh-rTW only (`resConfigs`); L2 astrology = real Meeus moon + standard ascendant with

## 5. Recommendations to proceed

**Path A — ship (recommended default):** do #1–#2 above → create Play Console app → closed testing
with 5–10 testers → fix telemetry-free feedback (crash reports arrive only if you later enable
Firebase; the conditional Data Safety answers for that are pre-written) → production staged rollout.
In parallel, borrow/use a Mac for #4 and drive toward TestFlight.

**Path B — award polish first:** run the remaining `docs/launch/UX_ROADMAP.md` prompts (2.x retention
tier: rescan ritual + journal prompts from the reading; 3.1 guided reflection; App Store screenshot
production with the Astraeus/brand kit). The four award-board items from the Design Room are already
built; what remains is content-depth and marketing surface.

**Watch-list (not blockers):** AGP 8.2.2 with compileSdk 35 builds under a suppress flag — schedule an
AGP/Gradle upgrade before OS 16 targets; dependency vintage is early-2024; Wear OS / widgets / IAP are
post-launch by design; `docs/store/shared/launch_checklist.md` is the live tick-list.
